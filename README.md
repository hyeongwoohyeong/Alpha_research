# Alpha Dashboard

개인 리서치 dashboard — 산업·종목 deep-dive 노트.

## 구조
- `index.html` — 단일 HTML dashboard. 사이드바에 스터디 노트(상)·관심 종목(하).
- `agents/` — Cowork/Claude Code multi-agent 시스템 prompt (Master 2 + Subagent 15 + Operations + Handoff).

## 배포
GitHub Pages — `Settings → Pages → Source: main, /(root)` 활성화 후 약 1분 뒤 `https://<USERNAME>.github.io/<REPO>/` 에서 접근.

## 모바일
iPhone Safari → 위 URL → 공유 → "홈 화면에 추가". 앱 아이콘처럼 한 번 탭으로 실행.

## 갱신
Cowork 환경에서 데이터 갱신 후 `git push`.
